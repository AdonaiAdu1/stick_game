# Stick Game (Nim)

## What This Does
A simple two-player game against the computer. You take turns removing 1-3 sticks from a pile. The one who takes the last stick wins. The computer uses a basic unbeatable strategy.

## Live Demo
**Try it instantly:** [Click here to run the game on OnlineGDB](https://onlinegdb.com/EY_ku13a_)

Just click "Run" and play in your browser. No setup needed.

## How to Play
1. Enter the total number of sticks.
2. Choose who goes first (yes = you, no = computer).
3. On your turn, pick 1, 2, or 3 sticks.
4. The game ends when no sticks are left.

## Computer Strategy
The computer always tries to leave a multiple of 4 sticks. This is a known winning strategy for this game.
